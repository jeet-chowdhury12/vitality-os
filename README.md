# 🏥 Vitality-OS: Smart Hospital Cloud & Clinical Intelligence

A full-stack, enterprise Smart Hospital Operating System featuring 9 integrated clinical and operational portals.

---

## ⚡ Quick Start for Teammates (Under 2 Minutes)

### Method 1: The Easiest Way (1-Click for Windows)
1. Make sure you have **Node.js** installed: [Download Node.js LTS](https://nodejs.org/) (if not already installed).
2. Simply double-click **`start-vitality-os.bat`** in this folder!
3. It will automatically install packages (first time only) and open the app in your browser at `http://localhost:3000/`.

---

### Method 2: Command Line (Windows, Mac, Linux)
Open your terminal inside this folder and run:

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev
```

Then open your browser and navigate to:
👉 **`http://localhost:3000/`**
